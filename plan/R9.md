## Quy ước chung
- **URL gốc:**
  - lấy từ **một nơi duy nhất**: hằng `SITE_URL` trong `scripts/site_config.py`, mặc định `https://example.github.io/autodev-sandbox/`;
  - `canonical`, `og:url`, `og:image` (URL tuyệt đối), `sitemap.xml` dùng giá trị này;
  - nếu HTML tĩnh phải ghi cứng thì test kiểm mọi chỗ khớp `SITE_URL`.
- **Meta:**
  - `og:title`, `og:description`, `og:type=website`, `og:url`, `og:image`, `og:image:width=1200`, `og:image:height=630`, `og:locale=vi_VN`;
  - `twitter:card=summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`;
  - `<link rel="canonical">`.
- **Ảnh chia sẻ:** `og.svg` 1200×630 dùng font, màu và minh hoạ của hướng đã chọn, có tên "Lười Code Studio" và câu chào; chụp thành `og.png` bằng Chrome (`screenshot.py`).
- **Favicon:** `favicon.svg` đơn giản lấy từ minh hoạ hero, `<link rel="icon" type="image/svg+xml">`.
- **JSON-LD:** `<script type="application/ld+json">` với `@context: https://schema.org`, `@type: ProfessionalService`, `name`, `description`, `url`, `email`, `areaServed`; L2 cho phép loại script này.

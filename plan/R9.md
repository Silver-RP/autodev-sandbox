# R9: SEO và chia sẻ

**Mục tiêu dự án:**
- Chia sẻ link có ảnh đẹp; máy tìm kiếm hiểu trang.
- Đẩy E1; giữ L1–L5, D1–D6, E4.

## Phạm vi
- **Trong:**
  - `site/index.html` (meta, JSON-LD);
  - `site/og.svg` (nguồn) và `site/og.png` (1200×630);
  - `site/favicon.svg`, `site/robots.txt`, `site/sitemap.xml`;
  - `scripts/site_config.py` (hằng `SITE_URL`) hoặc tương đương;
  - `tests/test_site_seo.py` (mới);
  - `scripts/screenshot.py` (thêm chụp cỡ tuỳ ý nếu chưa có).
- **Ngoài:** URL thật (R11 thay `SITE_URL`); bản tiếng Anh (R13).

## Quy ước chung
- **URL gốc:**
  - lấy từ **một nơi duy nhất**: hằng `SITE_URL` trong `scripts/site_config.py`, mặc định `https://example.github.io/autodev-sandbox/`;
  - `canonical`, `og:url`, `og:image` (URL tuyệt đối), `sitemap.xml` dùng giá trị này;
  - nếu HTML tĩnh phải ghi cứng thì test kiểm mọi chỗ khớp `SITE_URL`.
- **Meta:**
  - `og:title`, `og:description`, `og:type=website`, `og:url`, `og:image`, `og:image:width=1200`, `og:image:height=630`, `og:locale=vi_VN`;
  - `twitter:card=summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`;
  - `<link rel="canonical">`.
- **Ảnh chia sẻ:** `og.svg` 1200×630 dùng font, màu và minh hoạ của hướng đã chọn, có tên "Lười Code Studio" và câu chào; chụp thành `og.png` bằng Chrome (`screenshot.py`).
- **Favicon:** `favicon.svg` đơn giản lấy từ minh hoạ hero, `<link rel="icon" type="image/svg+xml">`.
- **JSON-LD:** `<script type="application/ld+json">` với `@context: https://schema.org`, `@type: ProfessionalService`, `name`, `description`, `url`, `email`, `areaServed`; L2 cho phép loại script này.

## Pre-mortem: đạt trên giấy mà hỏng thực tế thế nào?
1. **`og:image` sai cỡ hoặc trống:** → test đọc header PNG đúng 1200×630, file > 5 KB; reviewer nhìn ảnh.
2. **JSON-LD sai cú pháp:** → test `json.loads` nội dung thẻ và kiểm `@context`, `@type`, `url` = `SITE_URL`.
3. **URL tuyệt đối lệch nhau hoặc trỏ domain chưa có:** → test mọi URL tuyệt đối (canonical, og, sitemap, JSON-LD) bắt đầu bằng `SITE_URL`; R11 đổi một chỗ là đủ.
4. **`og.png` cũ so với `og.svg`:** → test `og.png` mới hơn `og.svg` (`mtime`).

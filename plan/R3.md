## Pre-mortem: đạt trên giấy mà hỏng thực tế thế nào?
Mốc chỉ thêm file tĩnh, không có trạng thái bền, nên không có rủi ro "kill ở giữa".
1. **Đạt nhờ dựng dữ liệu:** tìm `id="hero"` bằng `in` thì chuỗi trong comment hoặc `<div>` cũng qua. → dev-01 dùng parser đếm thẻ `section` thật có đúng id; test có ca âm (HTML mẫu với id trong comment phải bị đánh trượt).
2. **Nội dung giữ chỗ:** đủ khung, chữ là "Lorem ipsum". → dev-01: mỗi `section` ≥ 20 ký tự chữ hiển thị; cấm `lorem` / `TODO` / `placeholder` (không phân biệt hoa thường).
3. **Link CSS gãy:** test chỉ đọc HTML nên vẫn xanh. → dev-02 kiểm `<link rel="stylesheet" href>` trỏ tới file tồn tại; dev-03 tải `/style.css` qua HTTP thật.
4. **HTML hỏng:** thẻ không đóng làm sai bố cục. → dev-01 đếm thẻ mở và đóng của `section`, `main`, `header`, `footer` phải khớp.

## Task

### dev-01: `site/index.html` và test cấu trúc
- **Mô tả:**
  - Viết `site/index.html`:
    - `<!doctype html>`, `<html lang="vi">`;
    - `meta charset="utf-8"`, `meta name="viewport"`, `meta name="description"`, `<title>`;
    - `header` (tên "Lười Code Studio"), `main`, `footer`;
    - đúng một `<h1>`.
  - 4 `section`:
    - `#hero`: lời mời;
    - `#dich-vu`: 2–3 gói, giá chữ đùa;
    - `#cach-lam`: 3 bước, ví dụ "bạn kể, AI viết, tôi bấm deploy";
    - `#lien-he`: link `mailto:hello@example.com`.
  - Viết `tests/test_site.py` bằng parser stdlib.
- **Tiêu chí chấp nhận:**
  1. Test: `html` có `lang="vi"`; đủ `meta charset`, `meta viewport`, `meta description` (có `content` không rỗng), `<title>` không rỗng.
  2. Test: đúng một `<h1>`.
  3. Test: đủ 4 thẻ `section` thật với id `hero`, `dich-vu`, `cach-lam`, `lien-he`. Có ca âm: chuỗi HTML mẫu có id nằm trong comment hoặc `<div>` thì hàm kiểm trả trượt.
  4. Test: mỗi `section` có ≥ 20 ký tự chữ hiển thị; toàn trang không có `lorem` / `todo` / `placeholder` (không phân biệt hoa thường).
  5. Test: có `<a href="mailto:...">`; chữ hiển thị chứa "Lười Code Studio".
  6. Test: số thẻ mở và đóng của `section`, `main`, `header`, `footer` khớp nhau; không có thẻ `<script>`.

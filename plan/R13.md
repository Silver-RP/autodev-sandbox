## Quy ước chung
- **Bản Anh dùng chung tài nguyên:** `site/en/index.html` dùng `../style.css`, `../main.js`, cùng SVG (inline sao chép hoặc file chung). Không nhân bản CSS.
- **Cấu trúc giống hệt:** cùng tập id section (`hero`, `dich-vu`, `cach-lam`, `du-an`, `hoi-dap`, `lien-he`). Id giữ tiếng Việt không dấu để test so được; chữ hiển thị là tiếng Anh.
- **Nội dung tiếng Anh:**
  - dịch có chủ đích, giữ giọng tự giễu;
  - tên "Lười Code Studio" giữ nguyên (có thể kèm phụ đề "Lazy Code Studio");
  - giá chữ đùa chuyển văn hoá hợp lý (vẫn là đồ uống / bữa ăn).
- **`hreflang`:**
  - cả hai trang có `<link rel="alternate" hreflang="vi" …>`, `hreflang="en"`, `hreflang="x-default"` (trỏ bản Việt), URL tuyệt đối từ `SITE_URL`;
  - `canonical` mỗi trang trỏ chính nó.
- **Nút chuyển ngôn ngữ:** link thường (`<a hreflang="en" lang="en">English</a>` / `<a hreflang="vi" lang="vi">Tiếng Việt</a>`), không cần JS, đặt ở header.
- **Meta riêng cho bản Anh:** `og:locale=en_US` + `og:locale:alternate=vi_VN`; title và description tiếng Anh; `sitemap.xml` có cả hai URL.

# R11: Triển khai GitHub Pages

> **Điều kiện chạy:** leader đã bật GitHub Pages cho repo (Settings → Pages → Source: GitHub Actions) và cho biết URL. Repo đang **private**: Pages cho repo private cần gói GitHub trả phí, hoặc đổi repo sang public. Chưa có thì mốc dừng ở bước chuẩn bị với lý do "Pages chưa bật" (BLOCKED), không giả đạt.

**Mục tiêu dự án:**
- Trang có URL thật, tự cập nhật mỗi khi merge vào `main`.
- Đẩy E3; giữ mọi chỉ số khác.

## Phạm vi
- **Trong:**
  - `.github/workflows/pages.yml` (mới);
  - `scripts/smoke_pages.py` (mới) + test;
  - `scripts/site_config.py` (`SITE_URL` = URL thật);
  - cập nhật mọi URL tuyệt đối đã sinh từ `SITE_URL` (meta, sitemap, robots, JSON-LD, hreflang).
- **Ngoài:** tên miền riêng; sửa `ci.yml` (CI vẫn chỉ ruff + pytest).

## Quy ước chung
- **Workflow:**
  - `on: push` vào `main` (và `workflow_dispatch`);
  - quyền `pages: write`, `id-token: write`, `contents: read`;
  - `actions/checkout@v4`, `actions/configure-pages@v5`, `actions/upload-pages-artifact@v3` (thư mục `site/`), `actions/deploy-pages@v4`;
  - `concurrency: pages`, `cancel-in-progress: false`.
- **Phiên bản:**
  - bước build ghi `<meta name="version" content="${{ github.sha }}">` vào bản sao `site/` trước khi upload (thay một chỗ giữ chỗ `content="dev"` trong HTML);
  - không commit SHA vào repo.
- **`smoke_pages.py [--url URL] [--sha SHA]`:**
  - mặc định URL từ `SITE_URL`, SHA từ `git rev-parse origin/main`;
  - tải trang: 200, có "Lười Code Studio", `meta[name=version]` = SHA;
  - tải `/en/`, `/style.css`, `/og.png`: 200;
  - thử lại tối đa 10 lần, cách 30 giây (chờ deploy).

## Pre-mortem: đạt trên giấy mà hỏng thực tế thế nào?
1. **Deploy bản cũ hoặc dính cache:** → smoke so `meta[name=version]` với SHA `main`; thử lại có giới hạn.
2. **Repo private chưa bật Pages:** → mốc BLOCKED ở bước chuẩn bị; không tạo workflow chạy đỏ trên `main`.
3. **Kill giữa deploy:** → Pages deploy nguyên khối theo artifact; chạy lại workflow (`workflow_dispatch`) là đủ; smoke xác nhận.
4. **URL tuyệt đối còn trỏ `example.github.io`:** → test quét `site/` không còn chuỗi `example.github.io` sau khi đổi `SITE_URL`.

## Tiêu chí chấp nhận cấp mốc
1. `python3 "<plugin_root>/scripts/verify.py"` sạch.
2. Sau khi PR mốc được merge và workflow chạy xong: `uv run python scripts/smoke_pages.py` exit 0 (E3). Bước này chạy **sau merge**, nên supervisor hoặc leader chạy và ghi vào `docs/autodev/PROGRESS.md`.
3. `test_site_seo.py`, `test_site_i18n.py` xanh với `SITE_URL` mới.
